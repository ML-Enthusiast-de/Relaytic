# Build Slice Archive

This directory contains the bounded specifications used to build Relaytic.
Each file records the intent, acceptance criteria, and expected artifacts for
one implementation stage.

The archive is chronological. Statements such as "next target", "planned", or
"must land before" describe the state when that slice was written. They do not
override the repository's current status.

Current implementation boundary:

- product slices `00` through `15Z-R` are implemented
- paper-track slices `P0` through `P27` are implemented
- the verified public release remains a human action
- Slice `16A` is the next planned product slice

Use [`../../IMPLEMENTATION_STATUS.md`](../../IMPLEMENTATION_STATUS.md) for
current status and [`../../RELAYTIC_SLICING_PLAN.md`](../../RELAYTIC_SLICING_PLAN.md)
for future work.
