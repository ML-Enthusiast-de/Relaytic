# Generated Reports

This directory contains deterministic engineering and paper-evidence outputs.
Most reports are tied to the slice or paper stage that generated them. Their
status fields, blocked reasons, and next-step text must be interpreted in that
stage context.

These reports support audits and regeneration. They do not replace:

- [`../../IMPLEMENTATION_STATUS.md`](../../IMPLEMENTATION_STATUS.md) for the
  current implementation boundary
- [`../paper/README.md`](../paper/README.md) for the current manuscript and
  release workflow
- [`../../README.md`](../../README.md) for the public product path

Stage-local evidence is intentionally retained when a later stage resolves a
blocker. This preserves the decision trail without presenting the earlier
blocker as current project status.
